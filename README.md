# 四旋翼巡检仿真与操作台

ROS Noetic 工作区：PX4 SITL + Gazebo Classic、MID360 仿真、Faster-LIO 定位、全局 A* 平滑路线、EGO 局部规划和 Qt/RViz 综合操作台。当前处于仿真调试阶段，尚未完成实机验收。

## 启动

```bash
source /opt/ros/noetic/setup.bash
catkin_make -j1 -l1
source devel/setup.bash
bash src/drone_stack/scripts/start_simulation.sh
```

启动脚本启动 ROS、PX4/Gazebo 服务端和 Qt；Gazebo 客户端可另开 `gzclient`，需要与仿真相同的模型及插件环境。等待 Qt 显示 READY、健康正常后再授权、解锁、起飞。启动不会自动飞行。详见 [无人机栈说明](src/drone_stack/README.md)。

## 当前代码基线（2026-10-05）

- MID360 位于机体 `[0.27, 0, 0.10] m`，绕 Y 轴前倾 30°；包括雷达 IMU、前视和下视相机。
- Faster-LIO 位姿经过外参变换换算至机体中心，通过 `/mavros/odometry/out` 提供外部位姿。外部速度不参与 EKF 融合。ROS 使用 ENU/FLU，MAVROS 执行飞控 NED/FRD 转换。
- 全局 A* 最多扩展 15000 节点；同一完整平滑路线进入 EGO。管理器独立检查实际执行 B 样条、体积边界和障碍，持续发送 OFFBOARD 目标。
- Qt 黄色显示当前全局路线，紫色显示实际获准执行的 EGO 曲线，绿色显示实际轨迹，红色显示目标和机头朝向。支持连续目标队列、移动速度 0.1～1.0 m/s、可调虚拟天花板、相机画面和状态颜色。
- 终点接近减速与零末速度曲线；到达为三维球半径 15 cm、速度 ≤0.15 m/s、稳定 1 秒，后续目标仅在前一点到达后规划。
- 导航地图有原始占据证据、自由射线清除、膨胀引用更新及盲区保留；支持 `.dmap` 地面保存、加载及手动平移/航向对齐。尚不支持自动预建地图重定位。
- 最弱平移观测支持阈值 30，短暂异常警告、持续 0.5 仿真秒取消导航并 HOLD、持续 1 秒或严重异常降落。严重异常锁定后需检查并重启。
- 管理器曲线校验墙钟预算 2 秒、线程 CPU 预算 0.05 秒、递归节点上限 10000。全局 A* 节点预算与该曲线检查预算独立。

## 本次推送的已知问题与后续改造

这份提交作为修改前基线，保留现有实现及实验记录，以下问题尚未修复：

1. 到达确认使用硬 15 cm 门槛；小幅越界会退出确认并重规划，可能造成终点附近反向转头。拟增加退出滞回和安全末端收敛，保留最终到达标准。
2. 空闲区域出现占据/膨胀残留，需要核对原始占据、射线覆盖、地图坐标一致性与显示更新；有清除代码不等于所有场景已经正确清除。拟完善实测自由证据与地图层一致性。
3. 会话定位与预建地图初始位姿尚缺少完整流程。已选择：在线新建图自动设起点；预建地图通过 Qt 点位置并拖动朝向，完成地图对齐后放行导航。

这些问题未完成飞行回归，不应把本版本视为实机就绪版本。运行数据与详细进度见 [DRONE_SIM_PROGRESS.md](DRONE_SIM_PROGRESS.md)。

## 目录与数据

- `src/drone_stack/`：控制管理器、传感器桥接、Qt、启动配置和服务。
- `src/ego_planner/`、`src/faster_lio_main/`：规划与定位源码。
- `external/PX4-Autopilot/`：PX4 及仿真依赖；构建输出不纳入版本管理。
- `docs/simulation/`：可提交的小型实验分析记录。
- `start/logs/`、`start/qt_work/`、`start/maps/`、录包和检查点：本地生成数据，通过 `.gitignore` 排除。
