# 仿真验收与实验任务

2026-10-02 开始执行。通过有限测试不代表无任何缺陷；下表列出可复现的验收范围。真机阶段另行验收。

## 验收指标

- 冷启动至少 3 次：READY、授权解锁、显式起飞、悬停、降落自动上锁；解锁自行上升 < 0.05 m。
- 起飞相对高度误差 < 0.15 m；悬停稳定后 60 秒墙钟真值 Z 峰峰值 < 0.15 m，XY 各 < 0.20 m；LIO/真值位移误差 < 0.10 m。
- OFFBOARD 全程保持，位姿和目标消息持续，外部速度/GPS/气压高度融合标志为 0。
- 规划轨迹密集采样无膨胀体素碰撞，无地图边界穿越；执行无碰撞、到达误差 < 0.20 m。
- 中断/错误输入必须在明确超时内触发停止规划或飞控保护，拒绝非法指令，记录恢复状态。
- 相机处理画面和 TF 可用；仿真颜色目标识别只用于数据链路验收，不代表真实巡检模型。
